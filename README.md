# TotalBET 
Cel aplikacji: Portal do zakładów bukmacherskich oraz dostarczających dreszczyku emocji gier hazardowych
Autorstwa Kacpra Maciejowskiego i Bartosza Pitry

1. Planowane funkcje
   -Główna atrakcja: wyścigi konne
   -Pomniejsze zakłady: wyścigi, poker, blackjack, wojna
   -Techologia i dane: React, dane zapisane lokalnie, obsługa danych za pomocą JavaScript
   -Zagrożenia: dodawanie nielegalnych środków, wpływanie na wynik gry, kradzież danych użytkowników
   -Plan pracy: Tydzień 1: opracowanie struktury projektu, Tydzień 2 praca nad implementacją działania podstawowych funkcji projektu, Tydzień 3 dopracowanie wyglądu strony oraz praca nad udoskonaleniem jej działalności
